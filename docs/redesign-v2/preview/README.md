# Pongo OS v2 interactive preview

This is an isolated, static design prototype. It imports no production code, calls no API, uses no credentials, stores no data, and contains only fictional mock records.

## Open it

Either open `index.html` directly in a browser or serve this directory:

```bash
cd docs/redesign-v2/preview
python3 -m http.server 4173
```

Then visit `http://127.0.0.1:4173`.

## Demonstrated screens

- Command Center
- Open Orders and order-detail drawer
- Pick Orders station
- All Inventory
- Inventory by Location
- Receiving workspace
- Insights dashboard
- Integrations / WooCommerce status
- Settings
- Component gallery

## Demonstrated interactions

- Global and contextual screen switching
- Collapsible desktop context rail and off-canvas mobile navigation
- Command dialog, guarded confirmation modal and order detail drawer
- Table row and bulk selection
- Mock filters and tabs
- Populated, loading, empty and error states
- Toast feedback
- Correct and incorrect scanner feedback
- Responsive table-to-record-card behavior

All actions are visual demonstrations only.
