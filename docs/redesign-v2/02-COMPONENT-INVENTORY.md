# Component inventory

## Count and method

The audit covers **133 render-level components/primitives**: 130 capitalized render functions in `frontend/src/App.jsx` plus the three exports in `frontend/src/components.jsx`. Small formatting and payload helpers were reviewed with their owning components but are not counted as UI components.

The table groups related leaf components so every current name is recorded without pretending the frontend already has a mature shared-component boundary.

## Design-system promotion priorities

1. Shell: module rail, contextual navigation, command bar, signal tray.
2. Data: one table/grid, toolbar, pagination, row selection, action menu, mobile record card.
3. State: status tag, alert, inline error, skeleton, empty state, toast, live indicator.
4. Workflows: entity drawer, guarded action dialog, scan stage, progress stepper, audit timeline.
5. Forms: field, select, search, filter chip, validation message, sticky save/commit bar.

The redesign proposal does not refactor these components; this inventory is an implementation map for a later approved phase.
